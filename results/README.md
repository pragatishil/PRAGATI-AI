# Results

Organize generated outputs by scientific purpose rather than by the order in which they were produced.

- `tables/` — CSVs underlying manuscript tables
- `metrics/` — evaluation metrics
- `predictions/` — test/validation predictions
- `calibration/` — conformal and uncertainty outputs
- `robustness/` — robustness/domain-shift results
- `analysis/` — failure, attention and other diagnostic analyses
